# Phase 3: Knowledge Base Admin

## Scope Boundary For This Phase

Phase 3 turns the KB service and backend document control plane into an
admin-manageable Playbook knowledge base for athlete answers. Some backend
control-plane work started in Phase 1; this phase completes the admin UX,
contract alignment, status/retry flows, and end-to-end ingestion/search
verification.

## Definition of Done

- [ ] Admins can upload, view, tag, retry, and delete/archive KB documents.
- [ ] Ready documents are searchable by the athlete chat agent.
- [ ] Failed documents do not influence answers.
- [ ] Metadata needed for citations and conflict handling is returned by retrieval.
- [ ] Document admin actions are audited.
- [ ] KB-service API contract docs match the route shapes used by the backend provider.
