# Phase 3: Knowledge Base Admin

## Scope Boundary For This Phase

Phase 3 turns the KB service and backend document control plane into an
admin-manageable Playbook knowledge base for athlete answers. Some backend
control-plane work started in Phase 1; this phase completes the admin UX,
contract alignment, status/retry flows, and end-to-end ingestion/search
verification.

## Definition of Done

- [x] Admins can upload, view, tag, retry, and delete/archive KB documents.
- [x] Super admins can create KB collections with title, description, and icon, and archive empty collections.
- [x] Super admins can create, rename, archive, unarchive, and permanently delete unused archived global metadata tag presets.
- [x] Admin document tagging uses preset tag slugs instead of free-form metadata text.
- [x] Ready documents are searchable by the athlete chat agent.
- [x] Failed documents do not influence answers.
- [x] Metadata needed for citations and conflict handling is returned by retrieval.
- [x] Document admin actions are audited.
- [x] KB-service API contract docs match the route shapes used by the backend provider.
